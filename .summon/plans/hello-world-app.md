1. Set up the root route layout in `src/routes/__root.tsx` with the app shell structure (Outlet for child routes, basic HTML structure).
   - Expected outcome: The app has a basic page layout ready to display content.

2. Create `src/routes/index.tsx` as the home page that displays "Hello World" centered on the screen with a clean, welcoming design.
   - Expected outcome: Visiting the app shows "Hello World" prominently displayed on the home page.

3. Verify the app compiles and runs without errors.
   - Expected outcome: The app starts cleanly and displays the Hello World message in the browser.
